# UCDP Conflict Deaths: one dataset, two BI tools

UCDP Georeferenced Event Dataset (GED v26.1, 417,968 events, 1989-2025) loaded into PostgreSQL,
analysed in SQL, and visualised twice: once in **Metabase** and once in **Power BI**.

Full README (findings, data caveats, screenshots) coming soon.

## Layout
- `sql/` - view definition and practice queries (PostgreSQL)
- `metabase/queries/` - the 10 SQL questions behind the Metabase dashboard
- `powerbi/` - the Power BI project (.pbip)
- `images/` - dashboard screenshots
